A short orientation for readers seeing this project for the first time — where it started, what changed, and what we can say so far.

Where we started. The first version of this project was a brain hyperresearch setup: several autoresearch agents searching for encoding models in parallel, coordinated by a conductor in a hierarchical arrangement. It ran on a single dataset — the Natural Scenes Dataset (NSD) — and the whole loop was wired specifically to that data.

What changed. The search now sits on the NeuralSet / NeuralFetch unified data interface, so the same harness can be pointed at many different datasets (fMRI/image, fMRI/audio, MEG/audio) by flipping a single preset rather than rewriting the pipeline. Three things moved with it:

  • Unified data layer. Every stimulus and every recorded response is read through NeuralSet, so adding a dataset or a new subject is a config change, not a new harness.
  • A rebuilt feedback loop. The signal the agent learns from has been completely reworked — a structured, append-only ledger (one row per model: its idea, what it computes, held-out reward, and per-region predictivity) that gives the search far cleaner feedback than before.
  • Nonstop, region-targeted search. The agent runs continuously via the keepgoing launcher, and each run is rewarded on one chosen brain region at a time, so we can optimize models region by region instead of for a single global score.

What we can say so far (NSD, one subject). Optimizing per region, the picture already matches the prior we'd expect from the visual hierarchy:

  • Early visual cortex (V1/V2/V3): hand-written, never-trained models reach clearly higher predictivity — as anticipated, since these regions are dominated by Gabor-like oriented-energy and contrast computations that are easy to write by hand.
  • Ventral stream: in the ventral ROI, the best untrained model is now comparable to trained AlexNet for this one subject — a notable result given the model is never trained and only its ridge readout is fit.
