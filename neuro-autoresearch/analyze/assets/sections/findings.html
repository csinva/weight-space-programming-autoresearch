This loop evolves a hand-written, never-trained feature extractor (model.py): a stimulus image is mapped to features, a ridge readout is fit against recorded fMRI (the only thing fit — that fit is the evaluation), and held-out test_corr on NSD subject 01 is the reward. Each run rewards a single visual region, and the report compares the winner to both the logged identity/raw-pixel baseline and the documented trained-AlexNet reference.

The architecture the search converged on (in every region). Without being told to, the loop rediscovered the classical early-visual front-end:

  • Quadrature Gabor banks (orientations × spatial wavelengths) reduced to complex-cell energy √(cos² + sin²) — V1 simple→complex cells;
  • colour opponency (luminance, R−G, B−Y) — retinal/LGN channels;
  • log contrast compression followed by divisive normalization with a spatial-surround pool — Heeger's canonical cortical gain control;
  • raw pixels concatenated in as a low-level anchor.

On top of this shared core, each region added a distinct elaboration: a second scattering layer (Gabor-on-energy) for V2/V3, a wider normalization pool for V3's larger receptive fields, texture Gram matrices + GIST + random Fourier features for scene-selective PPA, colour histograms for EBA, and heterogeneous random conv banks for the face/word regions.

Key findings.

  1. V1 is the most predictable region and the simplest model wins it — a pure Gabor-energy model with a 3×3 surround norm. Predictivity then falls along the cortical hierarchy V1 > V2 > V3 > hV4 > category-selective regions.
  2. Every region's best model still predicts V1 best (~0.40 in the column below, regardless of which region was the reward). The region-specific machinery buys only modest gains on its own target — the models remain fundamentally low-level/V1-like and do not yet capture high-level category selectivity (FFA/PPA/EBA/VWFA stay ≈0.20–0.29).
  3. The baseline chart makes the main boundary clear: untrained encoders can match or beat AlexNet in early/mid visual cortex, but still trail the learned network in high-level category regions where semantics matter.
