Each run proposes fixed feature extractors, then the ridge readout asks: which hand-written computation makes brain activity easier to predict? The bars below sum the reward gains from improving steps that mention each principle. A single step can count for multiple principles because real models combine ingredients.

  • Gabor / oriented energy — quadrature filter pairs collapsed to √(cos²+sin²) give phase-invariant edge/contrast detectors (V1 complex cells).
  • Divisive normalization — dividing each unit by a pooled neighbourhood is the canonical cortical gain-control that decorrelates and equalises contrast (Heeger).
  • Colour opponency — luminance / R−G / B−Y channels mirror retinal–LGN coding.
  • Multiscale / spatial frequency — a bank of wavelengths covers coarse layout through fine detail; different regions weight the bands differently.
  • Scattering / second order — a Gabor layer applied to the first layer's energy captures the nonlinear pooling V2/V3 perform on V1 output (translation-stable).
  • Texture statistics — Gram / GIST / Portilla–Simoncelli summaries describe material and scene structure, which drives PPA and the ventral stream.
  • Random features — fixed random projections (RFF, random convs, codebooks) lift features into a high-dimensional kernel space without any training.
  • Pooling / retinotopy — foveal weighting and spatial grids encode where things are, not just what.
