Open-ended autoresearch · an AI agent searching the space of functions

Search for the computations that explain the brain

An AI agent writes and rewrites the code for a function f: stimulus → representation; a ridge readout to recorded neural activity scores it, and that score is the agent's reward. The agent can invent any computation — a wavelet bank, a kernel expansion, an energy hierarchy, not just a neural network — with its parameters written directly in code rather than learned from data. The object of the search is not a model that fits the brain but the function a brain region computes: what class of computation does it implement?

How the search works Read the best models

Not architecture search

The search space is the space of functions, not a fixed backbone family. A proposal can be Gabor energy, a scattering transform, a hashed lexical bag — anything computable under the contract. The NSD champion is an HMAX energy model, not a CNN.

Written, not fitted

Parameters are analytic or random-but-fixed, written directly in code. No gradient descent, and the function never sees the neural target — so a high score reflects the computation itself, not weights tuned to the data. What we recover is the function, not a fit to it.

An agent as the scientist

Autonomous LLM agents author, run, and revise the code — reasoning about mechanism, reading their own scores, and building on what worked. The search runs unsupervised for hours across a diverse pool.

01 · The search

An AI agent writes the function, reads its score, and rewrites it

The project began with one question: could a large language model, given a brain region and a way to score predictions, simply write the code for a function that predicts it — authoring the computation rather than tuning parameters? It can. The system scales that into a decentralized, always-on search.

What the agent is handed, and what it writes. Each proposer is an autonomous LLM agent. On every iteration it receives a concrete brief — the input/output contract, the source code of its own current best function, and an anonymized scoreboard of what rival approaches have scored — and it authors a new function as a self-contained program: choosing a front-end (oriented filters, kernels, character features), a nonlinearity, a pooling scheme, and how to lay out the representation. It reasons in natural language about the mechanism it expects to matter, then emits the code.

The reward and the feedback. It submits that function and the harness returns a single scalar reward — held-out predictivity of the neural activity — together with a per-region breakdown showing where it won and lost. That signal is not a gradient: the agent reads the score against its own prior notes, forms a hypothesis about what to change, and writes the next version. Propose → score → read → mutate, looping for hours, with a GPU evaluator fitting the readout and an optional conductor nudging the pool toward unexplored territory.

A pool of many agents, kept diverse. Scores are shared; source code is not. Each agent is an island that may read code only from its own best or one random other island — never a global champion — so approaches stay genuinely different instead of collapsing onto one recipe. The cross-island channels can be closed off entirely to recover an independent-loops baseline for controlled comparison. Diversity is the point: an open-ended search should populate many distinct hypotheses, not converge to one.

What the reward measures. On NSD and Triple-N the score is noise-ceiling-normalized — the mean fraction of explainable variance captured over the reliably-driven voxels or units — so 0.44 means 44% of the recoverable signal, not a raw correlation.

02 · The constraints

Why the weights are written, not learned — and why a size cap

A trained encoding model entangles two questions: does the brain resemble this computation, or this training set? Writing the parameters in code instead of learning them answers only the first — which is the one we want. The score then isolates the explanatory work in the function's structure: receptive-field layout, pooling, nonlinearity, the statistics it reads — rather than in what a training set taught it.

Because no gradient shapes the representation, predictivity is a clean readout of that structure. The 0.44 NSD result says a hand-specified energy hierarchy already captures 44% of the explainable variance in early+ventral cortex — telling us the computation, before learning is even in the picture.

A hard 1M-parameter ceiling is the forcing function for interpretability. Static and runtime guards also block pretrained weights, network access, and reading the neural target — so every champion is a small, self-contained, readable computation, not a black box you can only benchmark.

Two more constraints keep the readout honest: representations are strictly per-sample (no statistic leaks across a batch), and width is capped at D_out < 10⁴ so the ridge cannot simply memorize. The result is a champion you can read top to bottom and turn into a mechanistic claim — which is the whole point.

03 · What this opens up

Questions a fixed hypothesis class cannot ask

Because the search ranges over arbitrary agent-authored functions — not points in one architecture family — it can pose and answer questions that model-comparison studies structurally cannot.

Q1

Which primitives does a region need?

Read the champion for area X and ablate it: is fine-scale Gabor energy sufficient for early+ventral, or are co-occurrence and part statistics load-bearing? The code is the answer.

Q2

Do computations recur across brains?

Run the same search on macaque spikes, human fMRI, and human ECoG. Convergent primitives across species and recording modality are evidence for a shared computational motif.

Q3

What is the minimal computation?

Under a 1M-parameter cap, how close to the noise ceiling can a hand-written function get? The frontier traces the irreducible computational content of a region's responses.

Q4

Where is learning actually required?

The gap between the best written function and a trained network localizes what must be learned — separating the underlying computation from experience, region by region.

Q5

Can an agent invent something new?

Open-ended search can surface computations no one enumerated — hue×orientation conjunctions, content-word weighting — turning the search into a source of hypotheses, not just a fit.

Q6

Does the loop become a scientist?

Agents that propose, test, and revise code against neural data are a testbed for autonomous discovery — how far can decentralized search push scientific understanding on its own?

Vision · NSD · 0.44

An HMAX energy hierarchy

Gabor quadrature-energy over a fine scale/orientation ladder gives V1 edge power; HMAX max-pooling and a compressive nonlinearity add tolerance; random-weight conv layers with an abs (phase-invariant) nonlinearity build mid/high features; a cross-orientation Gram captures texture; a foveal pool reads the central object. Concatenated pools form the representation.

What it finds

Ventral predictivity is driven by fine-scale contrast energy with tuned compressive nonlinearities and co-occurrence statistics — the function's structure, not learned categories. 44% of explainable variance from under 1M parameters, none of them learned.

Language · iEEG · 0.063

A hand-built lexical–syntactic feature map

Words are encoded from character codes (no pretrained lexicon); the current word's n-gram form is hashed, a recency-weighted context bag up-weights content words over function words, a syntactic-category one-hot is read from a hand-coded lookup, and a bilinear term asks whether the word fits its topic — all read against high-gamma ECoG.

What it finds

Function words recur densely and swamp a naive context bag; up-weighting content words and exposing syntactic category measurably improves predictivity — the signal is carried by lexical topic and grammatical class.
