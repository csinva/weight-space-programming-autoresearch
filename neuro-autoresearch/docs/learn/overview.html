neuro·autoresearch is an AlphaEvolve-style research loop for neural encoding. An agent writes a fixed, never-trained model; a ridge regression reads its activations out against real recorded brain activity; the held-out correlation — test_corr — is the reward. The big idea

Encoding models: predict the brain from the stimulus

An encoding model answers a deceptively simple question: given what a person (or animal) is seeing or hearing, can we predict the pattern of brain activity it evokes? If a model's internal representation of the stimulus lines up with the brain's, a simple linear map should connect the two.

The pipeline has four moving parts. A stimulus — an image, a spoken word — is pushed through a fixed model that emits a feature vector. A ridge regression readout is then fit from those features to the recorded neural response. On a held-out test split we measure how well the predictions correlate with the real signal: the mean per-target Pearson r, which the project calls test_corr. That single number is the score.

Key idea

The model is never trained — its weights are written directly in code, with no optimizer and no backprop. Only the linear ridge readout is fit, and that fit is the evaluation. So the loop tests architecture, not learning.

The autoresearch loop · AlphaEvolve-style

An agent proposes, the harness scores, the loop hill-climbs

Discovery is automated. An LLM agent edits a single file — model.py — proposing a new fixed model along with an idea (its hypothesis) and a summary (what it does). The fixed harness evaluates that model exactly once and appends one row to a CSV.

Each row records the model's name, idea, summary, parameter count, test_corr, train_corr and the running best_so_far. An append-only iteration column counts the models tried — one row, one model, one step. The agent reads the history, forms a new hypothesis, and proposes again. Over many iterations the loop hill-climbs toward architectures that better explain the brain.

In this project

A model that raises or returns a bad shape is caught and logged as a status="error" row (NaN reward) instead of crashing the loop — so unattended overnight runs keep climbing safely.

In this project

Every dataset goes through the unified NeuralSet interface — no raw file or network I/O. The model always sees the same contract: a stimulus matrix X (N, D_in) in, an activation matrix (N, D_out) out, scored by held-out test_corr. Browse all of them on the Dataset Guides hub.

The goal

Beat a trained AlexNet — without ever training

The bar to beat is concrete. A frozen, ImageNet-pretrained AlexNet (its fc7 layer, 4096-dimensional) is read out with the same ridge against NSD's visual regions. That trained network — not a trivial pixel floor — is the baseline every never-trained candidate aims to match or surpass.

The empirical finding is sharp: hand-designed untrained models match or beat AlexNet in early and mid visual cortex (V1–V3), where structured filters go a long way — but fall short in high-level regions (FFA, PPA, EBA, VWFA), where category-tuned representations seem to require learning. A clean probe of architecture versus learning.

Watch out

Small test_corr differences (under ~0.005) are noise, not progress. And a high train_corr with a low test_corr means the readout overfit — it is not a better model of the brain.

Why it matters

Architecture, learning, and automated science

Because the candidate models are never trained, the loop isolates a question that is otherwise tangled up in optimization — and it asks that question across modalities and species at once.

Architecture vs. learning

Freezing the model strips away optimization, so a region where an untrained design already matches a trained net is one where structure, not learned weights, carries the representation.

A cross-modal testbed

fMRI, MEG, intracranial ECoG and macaque spikes — vision and language, human and monkey — all read out the same way. Theories of how brains represent the world face a single, comparable bar.

A step toward automated science

An agent proposing, scoring and iterating on scientific models — with an honest, reproducible reward — is a small, concrete instance of closing the research loop.
