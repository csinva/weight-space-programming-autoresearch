Field note 00 — Orientation

Most brain datasets show you one species through one instrument. Triple-N does something rarer: it takes the NSD shared-1000 — the 1,000 photographs every subject in the human Natural Scenes Dataset looked at inside an fMRI scanner — and shows those very same pictures to macaque monkeys, while microelectrodes record the firing of thousands of individual neurons.

Because the stimulus is held fixed across species and instrument, the comparison becomes unusually clean: the human-fMRI nsd preset and this macaque-spiking nnn preset are reading two very different signals evoked by identical pixels. This page is a field-guide to three things — the cross-species bridge Triple-N builds, the functional-patch architecture of monkey inferotemporal cortex, and how neuro-autoresearch turns it all into a benchmark for fixed, never-trained encoding models.

Key terms

NSD shared-1000
The 1,000 natural scenes viewed by all subjects of the human Natural Scenes Dataset — the common images that make cross-subject, and here cross-species, comparison possible.
EVC
Early visual cortex — V1, V2, V4 — the first, retinotopic stages of the visual hierarchy.
IT
Inferotemporal cortex — the high-level end of the ventral stream, organized into specialized patches for faces, bodies, objects, places and colour.
Spike reliability
How repeatable a neuron's response is across image repeats — the gate that separates signal-carrying units from noise.

Field note 01 — One stimulus, two brains

A bridge between species

Show the same photograph to a human in a scanner and to a monkey with electrodes, and you can ask a question almost nothing else lets you ask: how do two measurement worlds — and two species — encode the very same input?

Identical pixels, two species, two instruments — a controlled comparison the field rarely gets.

The Natural Scenes Dataset (Allen et al., 2022) scanned humans on tens of thousands of images, of which a curated 1,000 were shown to every subject. Those shared images are Triple-N's entire stimulus set — so a model that explains macaque IT spikes here, and human ventral BOLD in the nsd preset, is being asked the same question twice, in two organisms. That makes Triple-N a natural companion bench to the human NSD work already in this repo.

Field note 02 — Anatomy

The inferotemporal patchwork

High-level vision is not a uniform sheet. Monkey IT cortex is tiled into specialized patches — neighborhoods of neurons that light up preferentially for faces, for bodies, for objects, for places, for colour.

Triple-N samples both ends of the ventral stream. In early visual cortex (EVC) — V1, V2, V4 — receptive fields are small and tuned to edges, orientation and colour. Forward in the temporal lobe lies IT, where decades of work have mapped a recurring layout of category-selective patches. Triple-N's electrodes are placed against these patches, so a unit's area label tells you which functional neighborhood it belongs to.

EVC · V1/V2/V4 face · MF/AF body · MB/AB object · MO/AO place · LPP/PITP colour · CLC/AMC

In the harness these become the NEURO_ROI menu: the coarse streams EVC / IT, any patch family (MF, AB, LPP, …), an exact label (V1, V2, V4, …), or all. The reward narrows to whichever area you pick.

Field note 03 — The signal & the gate

From spikes to a reliable table

Each unit's response to each image is collapsed to a single firing-rate number — but only the units that respond repeatably are kept. Reliability is the gate between signal and noise.

Triple-N ships pre-averaged: for every recorded unit and every image, the evoked spiking is reduced to one value in a response_best table of shape [units × 1072]. The first 1,000 columns are the NSD shared-1000 scenes; the final 72 are face/body/object localizer images used to characterize each patch.

Not every unit is worth predicting. The release reports a split-half reliability per unit — how well the response to an image agrees across repeats. The harness keeps only units above a threshold (reliability > 0.4 by default, tunable via NNN_MIN_RELIABILITY): 35,494 of 47,503 units pass, pooled across all 90 sessions.

The table, precisely

response_best
[units × 1072] — mean firing rate per unit per image. Columns 1–1000 = NSD scenes; 1001–1072 = localizers.
reliability_best
Split-half repeatability per unit; the good-unit cut is 0.4.
area label
EVC vs IT, and the fine patch family, read from each electrode's recorded position.

How the reliable units split

Pooled across all sessions, the kept units divide between the two sampled streams, with the bulk in high-level cortex:

  • EVC — 8,740 units. Early visual cortex: V1, V2, V4.
  • IT — 21,214 units. The inferotemporal patches — by far the largest population.
  • Specialized patches. Within IT, families such as place (LPP) are individually addressable — e.g. ~407 reliable LPP units.

That heavy IT sampling is the point: the high-level ventral stream is exactly where untrained encoding models struggle most, so a dense, direct read of it is valuable.

The stimuli & the split

The stimulus images are bundled with the release (as an in-memory img_pool), so the nnn preset is fully self-contained: no separate NSD download or id-mapping is needed. The harness forms a fixed, image-disjoint split by striding the 1,000 scenes — every fifth image is held out — giving 800 training and 200 test scenes at the default test fraction.

A note on sample size

A thousand images is small next to the 22,000+ of some spiking sets — but it is plenty to fit the readout: with 768 input dimensions and per-target leave-one-out regularization, the ridge is well-posed at 800 training scenes (and the number of units never affects that conditioning). The real cost is reward noise: a 200-image test correlation wobbles more than a larger one, so treat test_corr differences below ~0.01–0.02 as ties.

Field note 05 — Brains, species & machines

Why this matters

Direct spikes, on stimuli shared with human fMRI, in the region where models are weakest — Triple-N sits at a uniquely informative intersection.

Most encoding benchmarks measure one species through one instrument. By replaying the NSD shared-1000 to monkeys and recording spiking — the cortex's actual currency, not the blood-flow shadow that fMRI sees — Triple-N lets a single fixed model be judged against both a human fMRI signal and a macaque neural signal evoked by the same pictures.

It also concentrates its sampling in IT, the high-level ventral stream. That is precisely where untrained, hand-designed models tend to lag a trained network most — so dense, reliable IT spiking is fertile ground for the project's central question: can the right never-trained computation match a trained one in high-level cortex?

A model that predicts a neuron is, in a real sense, a theory of what that neuron computes.

Put a candidate model up against real primate IT firing and the benchmark question becomes sharp and honest: how much of each patch — face, body, object, place, colour — can a fixed model explain? Triple-N turns that into a number you can chase.

Field note 06 — In this codebase

How neuro-autoresearch uses it

Same frame as every dataset here: a fixed, never-trained model turns the image into activations; a ridge regression reads those out to predict each unit's firing; held-out correlation is the reward.

The concrete contract

  • Stimulus X. The shown NSD scene, resized to 16×16 RGB and flattened to [0,1] → 768 dims (RawPixels), straight from the bundled image pool.
  • Target Y. Each reliable unit's mean firing rate for the chosen area — one value per unit per image.
  • Reward area. NEURO_ROI ∈ all / EVC / IT / a patch family (MF, AB, LPP…) / an exact label (V1, V2, V4…). Default IT.
  • Split. Strided, image-disjoint — 800 train / 200 test scenes.
  • Score. test_corr = mean per-unit Pearson r over the held-out scenes.

Run it

# reward = IT (default), scored over the 200 held-out NSD scenes
NEURO_DATASET=nnn python -m harness.run

# early visual cortex, or a single face patch
NEURO_DATASET=nnn NEURO_ROI=EVC python -m harness.run
NEURO_DATASET=nnn NEURO_ROI=MF  python -m harness.run

# tighten the reliability gate
NNN_MIN_RELIABILITY=0.5 NEURO_DATASET=nnn NEURO_ROI=IT python -m harness.run

Each run evaluates the current model.py once and appends a single row to results/NnnV1__<roi>.csv. Like tvsd, the ridge fits only the chosen area's units — run one loop per area; there is no multi-region corr_<area> panel.
