02

The Neural Code — how brains represent the world.

A photon, a phoneme, a face. None of them are "in" the brain. What is in the brain is a pattern of electrical activity that stands for them — and a set of rules, learned over evolution and a lifetime, for turning world into pattern. Those rules are the neural code.

You'll understand

  • What it means for neural activity to be a representation of the world.
  • How a single neuron speaks — spikes, firing rate, tuning curves, receptive fields.
  • Why meaning lives in populations and in the geometry of activity, not in single cells.
  • How RSA compares a brain, a model, and a monkey on equal footing.
  • Why rate vs temporal codes, noise correlations, and mixed selectivity each change what a population can convey.
  • Why population activity lives on a low-dimensional neural manifold, and what a state-space trajectory is.
  • Why "linearly decodable" is the criterion a good code must meet — the link to this project.

01 — The idea

What is a representation?

A representation is a systematic mapping from features of the world to patterns of neural activity that downstream regions can read and act on. The "neural code" is simply the rule-book of that mapping.

Strip away the mysticism and the definition is almost engineering. Some variable out there in the world — the orientation of an edge, the pitch of a vowel, the identity of your grandmother — gets mapped, reliably and systematically, onto some pattern of activity across a set of neurons. The mapping is a representation when two things hold: it is systematic (similar worlds map to related patterns, in a way that recurs across trials and across stimuli), and it is usable (a downstream region, with only the activity to look at, can recover the world variable and act on it). A pattern that no later region can read is, for the brain, not a code at all.

Three questions organize the whole field, and the rest of this chapter:

  • What is encoded? Which world variables does this region carry — orientation, color, faces, syntactic role?
  • How is it encoded? In firing rates? Spike timing? The activity of one cell, or the joint pattern across thousands?
  • For whom? A code only counts if some downstream reader can decode it. Readability is the criterion, and it returns at the end as linear decodability.
Key idea

A neural code is a mapping, not a place. The same world variable can be written in many formats; the brain "chooses" formats that make the variables its downstream regions need easy to read. Holding that reader's-eye view is the single most clarifying move in systems neuroscience.

02 — The atom of the code

The neuron & the spike

A neuron communicates in spikes — brief, all-or-nothing electrical pulses. What a spike means is the central puzzle: is it the count of spikes that matters, or their precise timing?

When a neuron's membrane voltage crosses a threshold it fires an action potential — a stereotyped ~1 ms voltage spike that travels down the axon to the cell's targets. Spikes are all-or-nothing: a bigger stimulus does not make a bigger spike, it makes more spikes. So the information a neuron transmits has to live in the pattern of spikes over time, not in any single spike's shape.

Two views of that pattern divide the field. A rate code says what matters is the firing rate — spikes per second, counted in some window. A temporal code says the precise timing of spikes (or their timing relative to a population rhythm, or to each other) carries information beyond the mean rate. Both are real: many sensory neurons are well described by rate, while phenomena like sound-localization in the auditory brainstem turn on microsecond-scale timing. For the encoding models in this handbook the relevant target is almost always a rate (or a slow proxy of it), so we lean on the rate view — while remembering it is a choice, not a law.

In the brain

Cortical neurons are noisy: present the identical stimulus twice and the exact spike times differ, often a lot. This trial-to-trial variability is why we average — and why every encoding score has a ceiling. A perfect model cannot predict the part of a neuron's response that is pure noise (Ch. 03 returns to this as the noise ceiling).

Rate versus temporal coding, in depth

The rate/temporal split is not one debate but several. A spike-count rate counts spikes in a fixed window on one trial; a PSTH rate is that count averaged over trials (Fig. 02.1); a population rate reads the instantaneous fraction of a pool that is active. All three discard fine timing. A temporal code claims information survives in that timing in at least one of several distinct senses, and the experimental bar differs for each.

  • Latency / first-spike timing. The time to the first spike after stimulus onset can carry more bits, faster, than the eventual count — exploited in fast vision and touch (Gollisch & Meister, 2008; rapid recognition under ~150 ms, Thorpe et al., 1996).
  • Coincidence / synchrony. Two cells firing together within a few milliseconds can signal something neither rate alone does — synchrony as a binding tag (Singer, 1999), though whether it is read out is contested.
  • Phase coding. A spike's phase relative to an ongoing rhythm carries information beyond its rate: hippocampal place cells fire at progressively earlier theta phases as an animal crosses a place field — theta phase precession (O'Keefe & Recce, 1993) — so position is read from when in the cycle, not just how fast.
  • Microsecond timing. Interaural-time-difference detectors in the auditory brainstem resolve sub-millisecond spike-arrival differences to localize sound — timing precision no rate code could supply.

The honest summary is that the brain is multiplexed: rate and timing coexist, often in the same cells at different scales, and the live question is always what a downstream reader can actually use. Precise-timing claims are held to a high bar precisely because a temporal code is only a code if some mechanism decodes it — the reader's-eye view of §01 again.

Going deeper — is variability "noise"?

Calling sub-Poisson jitter "noise" presumes the brain treats it as such. Two cautions. First, cortical spiking is often near-Poisson (variance ≈ mean, a Fano factor near 1), so a fixed count is genuinely ambiguous — but the variability is partly stimulus-driven and shared across cells, not private noise. Second, some apparent timing precision is real signal a coarse rate window throws away. The encoding harness in this handbook targets a slow rate proxy (an HRF-peak fMRI response), so it lives squarely on the rate side — a modeling choice that is adequate for fMRI but would discard exactly the timing structure a spiking study cares about.

Quick check — Why is sub-millisecond sound localization the textbook case against a pure rate code?
Because the relevant variable — which ear a sound reached first — is encoded in spike-arrival times on the order of microseconds. Averaging spikes into a firing rate over even a few milliseconds destroys exactly the information the system needs, so coincidence-detecting neurons must read timing directly. Rate codes are fine where the variable changes slowly; they fail where it lives in the timing itself.

03 — Selectivity

Tuning curves & the preferred stimulus

A tuning curve plots a neuron's average response as a function of some stimulus dimension. Its peak is the neuron's preferred stimulus; its width is the neuron's selectivity.

Vary one feature of the world — the orientation of a bar, the direction of motion, the frequency of a tone — and measure the neuron's mean firing rate at each value. Plot rate against feature and you get a tuning curve. Most cortical tuning curves are smooth and single-peaked: the neuron fires hardest for one value (its preferred stimulus) and progressively less as the feature moves away. The bandwidth of that curve sets the neuron's selectivity — a narrow curve is picky, a broad curve is permissive.

The canonical example is orientation tuning in primary visual cortex, discovered by Hubel & Wiesel (1962): a V1 neuron fires vigorously for an edge at, say, 45° and falls silent for one at 135°. Crucially, no single neuron knows the orientation — it only reports "how much I like what I'm seeing." Reading the orientation off requires comparing across many differently-tuned neurons, which is exactly the population story of §05.

Watch out

A tuning curve is an average over many trials. On any single trial the neuron's spike count is noisy, so a single firing rate is consistent with a range of stimuli. This ambiguity is not a flaw to engineer away — it is precisely why the brain reads populations, where many noisy, overlapping curves average out into a precise estimate.

04 — Where & what

Receptive fields

A neuron's receptive field is the region of input space it "watches" — a patch of retina, a band of frequencies — and the specific feature within that patch that drives it.

A V1 neuron does not respond to the whole visual world; it responds to a small patch of the visual field — its receptive field (RF). But location is only half the story. Within that patch, the neuron is tuned to a particular spatial structure. Retinal ganglion cells and LGN neurons have center-surround RFs — an excitatory center ringed by an inhibitory surround (or vice versa) — making them edge-and-contrast detectors that ignore uniform illumination. V1 simple cells have elongated, oriented RFs beautifully approximated by Gabor filters — a sinusoidal grating windowed by a Gaussian, tuned to a position, orientation, and spatial frequency all at once.

The same idea generalizes across modalities: an auditory neuron's RF is a region of the time–frequency plane (a spectro-temporal receptive field); a somatosensory neuron's is a patch of skin. The RF concept is the bridge from §03's abstract "stimulus dimension" to concrete input space — and the Gabor shape will return in §08 as something codes learn from natural images, and again in Ch. 04 and Ch. 06 as the first layer of a convolutional net.

05 — From one neuron to many

The population code

No single neuron carries a stimulus precisely. But many coarsely-tuned neurons, read together, pin it down exactly — the population code.

Recall the ambiguity from §03: a single firing rate is consistent with a range of stimuli. The resolution is to read many neurons at once. If a hundred neurons tile a feature dimension with overlapping tuning curves, then for any stimulus value some neurons fire a lot, some a little, and the whole vector of responses is unique to that value. Decoding is then just: "which stimulus best explains this pattern of firing?" The population is precise even though every individual is vague — coding theorists call this coarse coding, and it is one of the most important ideas in the field.

A famous concrete instance is the population vector of Georgopoulos et al. (1986) in motor cortex. Each neuron has a preferred movement direction; on a given movement, you weight each neuron's preferred-direction vector by how hard it is firing and sum them. The resulting vector sum points, strikingly accurately, in the direction the animal actually moves — direction read straight out of a population of broadly-tuned cells.

Key idea — three coding schemes

Local / "grandmother cell" coding: one stimulus → one dedicated neuron (efficient to read, fragile, biologically rare). Dense / distributed coding: every stimulus lights up many neurons and every neuron joins many stimuli (robust, high-capacity, what populations mostly do). Sparse coding: each stimulus activates only a small fraction of available neurons — a middle ground that is metabolically cheap and, as §08 shows, statistically optimal for natural inputs.

Local vs distributed, on the sparseness axis

Local and distributed are not a binary but the two ends of a single sparseness axis — how many neurons fire for a typical stimulus, and how many stimuli a typical neuron answers to. A pure labeled-line code (one line per message) sits at one extreme: trivial to decode, but it needs a neuron per concept and degrades catastrophically if that neuron dies. A fully dense distributed code sits at the other: every neuron participates in every stimulus, maximizing capacity but tangling the variables together. Real cortex lives between them, and the empirically favored regime is sparse-but-distributed — a small, overlapping committee per stimulus, combining the readability of local codes with the robustness and capacity of distributed ones.

The famous-seeming exception sharpens the rule. Quiroga et al. (2005) found human medial-temporal-lobe neurons that fired selectively to one person — the "Jennifer Aniston cell" — across photos, drawings, even the written name. Tempting to call these grandmother cells, but they are better read as the sparse, invariant, conceptual end of a distributed code: each concept engages a small set of such cells, and each such cell answers to a small set of related concepts. Selectivity that abstract is a feature of the geometry, not proof of a literal one-neuron-per-grandmother architecture.

Going deeper — why "grandmother cells" almost certainly don't exist (as usually meant)

The strong grandmother-cell hypothesis fails on three counts. Capacity: a dedicated cell per recognizable concept far exceeds plausible neuron counts. Robustness: losing the one cell would erase the concept, which it does not. Sampling: recording a concept-selective cell at all, from a tiny electrode sample, implies many such cells per concept — i.e., a sparse population, not a singleton. The lesson for encoding models: even a region with strikingly selective single units is read out as a population geometry, which is exactly what the ridge readout in this project operates on.

06 — Activity as geometry

Representational geometry

Treat a population's activity as a point in a high-dimensional space. Then meaning lives in the relationships — the distances and angles between points — not in any single axis.

A population of N neurons defines an N-dimensional state space: each axis is one neuron's firing rate, and the population's response to a stimulus is a single point. Show many stimuli and you get a cloud of points. Two stimuli that evoke similar firing patterns sit close together; dissimilar ones sit far apart. The shape of this cloud — its representational geometry — is where the code's structure becomes visible.

Two facts make this powerful. First, the points rarely fill the space; they lie on a lower-dimensional curved surface, a neural manifold, whose intrinsic dimensionality is far smaller than N. A ring of orientations traces a 1-D loop through a high-dimensional space; a smoothly varying stimulus traces a smooth curve. Second, this reframing is unit-agnostic: it never asks what neuron #37 "means." It asks only about relationships — which is exactly what lets us compare a brain to a model that has no neuron #37 at all (§07).

07 — Comparing systems

Representational Similarity Analysis

Characterize any system — a brain area, a model layer, another species — by its RDM. Then compare systems by comparing their RDMs, abstracted away from individual units entirely.

The deep problem in comparing a brain to a model is that they have no common parts: a voxel is not a unit, a macaque IT cell is not a human fMRI signal. Representational Similarity Analysis (RSA), introduced by Kriegeskorte, Mur & Bandettini (2008), dissolves this by characterizing each system only through its RDM — the geometry of pairwise stimulus distances from §06. Two systems can then be compared by correlating their RDMs, even though they share not one neuron, voxel, or unit.

This is what makes RSA the lingua franca for brain ↔ model ↔ species comparison. Build an RDM from human fMRI, another from a deep net layer, a third from monkey spiking — and ask: do they carry the same structure? Where two RDMs agree, the systems represent the stimuli the same way, regardless of how their individual units are wired.

Quick check — What does an RDM deliberately throw away, and why is that a strength?
It discards the axes — which unit, voxel, or channel carried what — keeping only the pairwise dissimilarities between stimulus responses. That abstraction is the point: it makes two systems with no shared parts (an fMRI region and a deep-net layer) directly comparable by their relational structure. The cost is that RSA is blind to anything an invertible re-mixing of the units would leave the distances unchanged — it sees representational geometry, not the code's specific coordinate format.

08 — What makes a code good

Decodability & efficient coding

A code is "good" to the degree that the variables a downstream region needs are linearly readable from it. And the codes brains actually use look shaped by the statistics of the natural world.

Return to the reader's-eye view from §01. A downstream neuron's most natural operation is a weighted sum of its inputs followed by a threshold — a linear read, essentially. So the practical criterion for a useful code is linear separability / decodability: can the relevant variable be recovered by a linear function of the activity? If object identity is linearly readable in IT but tangled in V1, then IT has done the representational work — it has untangled the categories into a geometry a simple reader can use. This is precisely the criterion the encoding harness in this project operationalizes, with a linear ridge readout.

Why do real codes have the structure they do? The efficient coding hypothesis (Barlow, 1961) says sensory systems are shaped to represent natural inputs economically — removing the redundancy in natural signals so each spike carries as much information as possible. Made quantitative for vision by Olshausen & Field (1996): train a model to reconstruct natural image patches using only a small fraction of active units (a sparse code), and the learned features come out looking like oriented, localized, Gabor-like filters — the very V1 receptive fields of §04, derived from image statistics alone. The world's structure, not a hand-design, picks the code. This foreshadows Ch. 04 (the visual hierarchy) and Ch. 06 (why deep nets trained on images recover similar features).

Key idea

Two complementary lenses on "a good code." Decodability is the downstream test — are the needed variables linearly readable? Efficient / sparse coding is the upstream principle — is the code economical for natural inputs? Remarkably, optimizing the upstream objective on natural images produces the Gabor receptive fields that make downstream reading easy. Structure in the world, an efficiency pressure, and readability all point to the same code.

09 — Shared variability

Noise correlations & population coding

Neurons don't fluctuate independently. The structure of their shared trial-to-trial variability — the noise correlations — can either limit a population's information or, surprisingly, help.

Split a neuron's response into two parts: the signal (how its mean rate depends on the stimulus, the tuning curve of §03) and the noise (its trial-to-trial wobble around that mean at a fixed stimulus). The correlation of mean rates across stimuli between two cells is the signal correlation; the correlation of their wobbles at a fixed stimulus is the noise correlation (often written rsc, typically a small positive 0.1–0.2 in cortex). Naïvely you'd hope averaging many neurons cancels noise — but only if the noise is independent. When it is shared, no amount of pooling removes it, and the population's information saturates.

The decisive result is that what matters is the geometry of noise relative to signal. Averbeck, Latham & Pouget (2006) made the logic crisp: noise that pushes the population along the same direction the signal moves (the stimulus-change axis) is information-limiting — it masquerades as a stimulus change and cannot be averaged away. Noise orthogonal to that axis is harmless, and noise that is anti-aligned can even improve decoding. So "positive noise correlations are bad" is a myth: the same average rsc can help or hurt depending on how the noise cloud is oriented against the signal direction — and against the readout. This is why information-limiting (differential) correlations, even if tiny, set the true ceiling on a large population.

Watch out

You cannot judge a population's information from single-neuron tuning plus the average noise correlation. Shuffling trials to "remove" correlations (the common control) destroys exactly the geometry that decides decodability — and a shuffle can make a population look more or less informative than it really is. The structure, not the scalar, is the thing.

Quick check — Two neurons have a +0.2 noise correlation. Is that good or bad for decoding?
Unanswerable as stated — that's the point. If the shared fluctuation lies along the axis that separates the stimuli (differential / information-limiting correlation), it caps the information no matter how many neurons you add. If it lies across that axis, it's harmless or even helpful. The sign and magnitude of rsc alone don't determine the effect; its orientation relative to the signal direction does (Averbeck, Latham & Pouget, 2006).

10 — High-dimensional codes

Mixed selectivity & dimensionality

Neurons that respond to nonlinear combinations of task variables look messy — but that mess is what lets a simple linear reader separate situations a tidy code never could.

A pure-selectivity neuron answers to one variable — "this cell codes color, that one codes shape." Intuitive, but limited: with pure cells, a downstream linear reader can only separate stimuli that already differ along a single coded axis. Many prefrontal and association-cortex neurons instead show mixed selectivity — they respond to combinations of variables, and crucially to nonlinear combinations (responding to "stimulus A during rule 1" in a way not predicted by adding the A-response and the rule-1-response). Rigotti et al. (2013) showed these nonlinear mixed-selective cells are not noise: they lift the population into a high-dimensional space where many more task conditions become linearly separable.

The geometry is the punchline (Fusi, Miller & Rigotti, 2016). Nonlinear mixing acts like the feature expansion of a kernel method: it raises the dimensionality of the representation, and with P conditions placed in high-enough dimension, almost any labeling of them — any task the animal might be asked — can be read out by a single linear boundary. A pure code is low-dimensional and only handles linearly-related tasks; a nonlinearly mixed code trades interpretability for a representation in which the hard work is already done for a linear reader. This is the same currency this whole project trades in: linear decodability (§08).

Key idea

There is a tension worth holding: high dimensionality (from nonlinear mixing) maximizes how many tasks a linear reader can solve, while low dimensionality (a clean manifold, §11) maximizes generalization to new conditions. Cortex appears to sit at a regulated point between them — "as high-dimensional as the task allows, no higher." The encoding harness inherits this directly: a richer model representation can be more linearly decodable yet less able to generalize across subjects.

Quick check — Why does adding a nonlinear mixed-selective neuron help a linear readout?
Because it raises the representation's dimensionality. Conditions that were collinear or XOR-arranged in the low-dimensional pure code get pushed onto a new, independent axis; in that higher-dimensional space a single hyperplane can separate label assignments that no line could separate before. It's the kernel-trick intuition: do the nonlinearity in the representation so the decoder can stay linear (Fusi, Miller & Rigotti, 2016).

11 — Dynamics on a manifold

Neural manifolds & state-space dynamics

Population activity rarely uses all its dimensions. It is confined to a low-dimensional curved surface — a neural manifold — and computation unfolds as a trajectory moving across it over time.

§06 introduced the population as a point in N-dimensional state space; §11 sets that point in motion. Record hundreds of neurons during a behavior and the activity does not roam freely through all N dimensions — it stays on a neural manifold of far lower intrinsic dimension, spanned by a handful of population-level patterns (often found with PCA or related methods; see Saxena & Cunningham, 2019). Over the course of a movement or decision, the state traces a smooth neural trajectory across that surface. The manifold is the repertoire of achievable states; the trajectory is the computation actually running.

This dynamical view reframed motor cortex. Churchland, Cunningham and colleagues (2012) showed reach-related activity is captured by low-dimensional rotational dynamics — the population orbits a fixed point rather than each neuron faithfully coding a movement parameter. And the manifold is remarkably stable: Gallego et al. (2017) found the same low-dimensional manifold re-used across tasks and preserved over months, so the brain may compute by steering trajectories within a stable subspace rather than by reconfiguring single-cell tunings. The upshot for encoding: the signal a readout can exploit lives in those few manifold dimensions, and a model's representation is good to the extent its geometry aligns with them.

Going deeper — manifold vs the harness's static readout

This handbook's encoding harness reads out a static response (an HRF-peak per voxel), so it sees the manifold's geometry but not its dynamics — it asks whether a model's per-stimulus points land where the brain's do, not how the state flows between them. That's appropriate for slow fMRI, but it is why the dynamical-systems literature lives mostly in spiking and Neuropixels work, where millisecond trajectories are visible. Same state space, different temporal resolution.

12 — Tying it back

In this project

Everything above is what the encoding harness measures. A proposed model's activations are a representation; the ridge readout asks whether that representation aligns, linearly, with the brain's.

In this project — neuro-autoresearch

In neuro-autoresearch, an agent proposes a fixed, never-trained model — a plain callable X (N, D_in) → activations (N, D_out) whose weights are written directly in code. Those activations are exactly a representational geometry: every stimulus becomes a point in the model's state space (§06). The ridge regression readout then learns a linear map from the model's geometry to the brain's recorded activity — the operational form of the linear-decodability criterion of §08. The model is never trained; only this linear readout is fit, and that fit is the evaluation.

The reward, test_corr — the mean per-target Pearson r on a held-out split — asks, target by target, whether the model's representation aligns with each individual neuron or voxel. A per-target correlation is the unit-level cousin of the RSA logic in §07: instead of comparing whole RDMs, it checks point-by-point whether the model can be linearly read out into each recorded response.

Because the harness frames every dataset the same way, it compares representations across species and modalities — human fMRI (NSD), human iEEG/MEG language data, and macaque spiking (the TVSD field-guide) — all read out by the same linear ridge. The recurring empirical finding is itself a statement about codes: hand-designed untrained models match a trained AlexNet in early/mid visual cortex (V1–V3), where the Gabor-like code of §04 and §08 is close to the answer, but fall short in high-level regions (FFA/PPA/EBA/VWFA), where the right representation appears to require learning.

So the chapter's arc maps directly onto the harness. Representation (§01) is what a model proposes; tuning & receptive fields (§03–04) are what good early-vision models hard-code; population, geometry & manifolds (§05–06, §11) are the level the readout actually operates on; noise correlations (§09) and mixed selectivity (§10) set what that population can even convey; decodability (§08) is the reward's logic; and RSA (§07) is the conceptual sibling of per-target correlation. The next chapter turns to how the brain activity on the right-hand side of that map is measured in the first place.

Test yourself

Check your understanding

Pick an answer to see why it's right or wrong. Score: 0 / 8

  1. 1. A tuning curve plots a neuron's response against a stimulus dimension. What is the single most accurate statement about what it represents?

    Why: A tuning curve is a trial-average; on any single trial the count is noisy, so one rate is consistent with a range of stimuli (that ambiguity is exactly why populations are read out). It is a property of one neuron, not a population decoder.

  2. 2. In the Georgopoulos population-vector readout of movement direction, how is the decoded direction obtained?

    Why: The population vector is a weighted vector sum: each cell "votes" with its preferred-direction vector, weighted by how hard it fires, and the resultant points in the actual movement direction. Precision emerges from the crowd, not from any single broadly-tuned cell.

  3. 3. What chiefly distinguishes a distributed code from a local ("grandmother cell") code?

    Why: The axis is sparseness — how many neurons per stimulus and how many stimuli per neuron. Distributed coding spreads each item across an overlapping committee (robust, high-capacity); a true labeled-line/local code needs a dedicated cell per item (easy to read but fragile and capacity-limited). Timing vs rate is a separate axis entirely.

  4. 4. A representational dissimilarity matrix (RDM) captures a system's representational geometry. What does it deliberately abstract away?

    Why: An RDM keeps the relational structure (distances between response patterns) and discards which unit coded what. That's precisely what lets RSA compare a brain region and a model layer that share no parts — but it also makes RSA blind to the specific coordinate format, seeing geometry rather than the literal code.

  5. 5. Which scenario is the strongest evidence for a genuinely temporal (not rate) code?

    Why: The localized variable lives in when spikes arrive (microsecond interaural timing), which a firing-rate window would erase. The other options are all rate phenomena — more spikes for the preferred/stronger stimulus — fully captured by a mean rate.

  6. 6. Why does adding neurons with nonlinear mixed selectivity help a downstream linear decoder?

    Why: Nonlinear mixing is like a kernel expansion: it lifts the conditions into a higher-dimensional space where many more labelings (including XOR-like ones) become linearly separable. Pure (one-variable) selectivity does the opposite — it keeps the code low-dimensional and only handles linearly related tasks (Rigotti et al., 2013).

  7. 7. Two neurons have a positive average noise correlation. What determines whether this helps or hurts population decoding?

    Why: Decodability depends on the geometry of noise versus signal, not the sign or size of rsc. Variability aligned with the stimulus-change axis masquerades as a stimulus change and can't be pooled away (differential correlations); orthogonal variability is averaged out (Averbeck, Latham & Pouget, 2006).

  8. 8. "Neural population activity lies on a low-dimensional manifold." What does this mean, and why does it matter for a linear readout?

    Why: The reachable states fill only a low-dimensional curved subspace; computation is a trajectory on it. Because the useful variance lives in a handful of modes (≪ N), a linear readout of those modes recovers the relevant variable — the same logic the encoding harness leans on (Saxena & Cunningham, 2019).

Key terms

Spike (action potential)
A neuron's ~1 ms all-or-nothing voltage pulse — the cortex's unit of communication.
Firing rate
Spikes per second in a window; the variable a rate code (and most encoding targets) reads out.
Tuning curve
A neuron's mean response as a function of a stimulus dimension; its peak is the preferred stimulus, its width the selectivity.
Receptive field
The region of input space a neuron watches and the specific feature within it that drives the cell (center–surround, Gabor).
Population code
A stimulus represented by the joint activity of many coarsely-tuned neurons; precise even when each unit is vague.
Distributed / sparse coding
Distributed: many neurons active per stimulus. Sparse: only a small active fraction — economical and natural-image-optimal.
Rate vs temporal code
Whether information lives in spikes-per-second (rate) or in precise spike timing/phase/synchrony (temporal); the brain multiplexes both.
Noise correlation (rsc)
Correlated trial-to-trial variability between neurons at a fixed stimulus; information-limiting when aligned with the signal axis, harmless or helpful otherwise (Averbeck et al., 2006).
Mixed selectivity
A neuron responding to nonlinear combinations of variables; raises population dimensionality so more tasks become linearly separable (Rigotti et al., 2013).
Neural manifold
The low-dimensional curved subspace that population activity is confined to; computation is a trajectory moving across it (Saxena & Cunningham, 2019).
Representational geometry
Neural activity as points in a high-dimensional state space, where distances and angles between stimuli carry the meaning; often a low-dimensional manifold.
RDM
Representational dissimilarity matrix — the table of pairwise distances between every stimulus's response pattern; a unit-agnostic summary of geometry.
RSA
Representational Similarity Analysis — comparing systems (brain, model, species) by comparing their RDMs (Kriegeskorte et al., 2008).
Sparse coding
An efficient-coding objective: reconstruct natural images with few active units; yields Gabor-like receptive fields (Olshausen & Field, 1996).
