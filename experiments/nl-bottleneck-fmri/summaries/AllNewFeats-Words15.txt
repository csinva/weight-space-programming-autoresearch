This model has no training. It is one transformer layer with hand-set weights that turns each 10-gram into a 1024-dimensional vector of random-embedded tokens. The input is the lowercased characters of the text, with last-word characters embedded differently from earlier ones. After them come md5-hashed tags (4096 buckets) for each word, oldest to newest: function-word identity (about 100 words), word length capped at 15, first and last letter, skip-bigram with the word two back, a suffix-stripped stem, and the word's character 2- to 5-grams with boundary markers. The current word's unigram hash comes last.

Every token gets a fixed Gaussian vector. Eight heads, each covering 128 dimensions, softmax-pool these vectors with position-based decay rates from 0 to 6. The readout adds the current word's hash vector to the pooled vectors, then applies LayerNorm. It also carries large sequence-length values (n and 6n²/512).

Approximations: a LayerNorm before attention defeats the intended recency. Pooling instead favours the earliest characters of the 10-gram and shrinks later hash tokens. To rebuild, combine hashed n-gram bags, current-word identity, primacy-weighted character context and a length scalar. Dependencies: numpy, torch, md5; no lexicons or pretrained models.
