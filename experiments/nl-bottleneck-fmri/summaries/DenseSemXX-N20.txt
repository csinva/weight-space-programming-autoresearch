This model is an untrained, hand-wired one-layer transformer with a 1,024-dimensional output. It effectively combines semantic-category counts with recency-weighted hashed word identity. Each lowercased, whitespace-split 10-gram becomes character tokens followed by md5-hashed tokens per word (4,096 buckets, random Gaussian embeddings in dims 563–1023): length bucket, first+last letters, skip-bigram, crude stem, character 2- to 5-grams, then whole-word identity, ordered oldest to newest. Words in a hand-made lexicon of about 70 semantic categories (BODY, FAMILY, MOTION, EMOTION, etc.) add tokens that set 8 repeated dims per category to 10,000.

Eight heads each pool their own 128-dim slice with a different exponential recency decay. Head 0 is a uniform mean, so it yields the fraction of tokens in roughly the 15 alphabetically-first categories (ABSTRACT to COLOR). The hash-dim heads decay sharply, so they mostly encode the last 1–3 words' identities, plus the last word's hash added directly. A final LayerNorm rescales each row by total token count (roughly character count) and leaks position values. This is approximate: LayerNorm distorts the decay, and character and subword tokens get little weight. It uses PyTorch and md5.
