# LEAN new-held-out-test package (patient1, Nov 6–7 2026)

Rerun of every LEAN autoresearch trial on the Figure 1 main line, and of the LEAN-v20 variance
partitioning, on 317 chunks the search never used. The training set and every fit are unchanged.
Start with **`NEWTEST_REPORT.md`** (results, methods, validation, how to reproduce, file map).

- `figures/` — new-test Figures 1 and 2 (`*_newtest.png/pdf`) and the old-test originals
- `results/results_table.csv` — one row per trial: old- and new-test scores
- `varpart/RESULTS.md` — variance partitioning tables on the new test
- `protocol/PROTOCOL.md` — the test-set rule, fixed before scoring
- `both_lean_whisper/` — LEAN-v20 + Whisper ("Both") and the LEAN-vs-Whisper variance partitioning (report §12)

Companion package: `LEAN_replication_package.zip` (the original June search and the Nov 5 analyses).
