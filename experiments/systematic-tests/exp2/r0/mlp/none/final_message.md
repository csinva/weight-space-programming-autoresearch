**Reasoning used**
- Early layers (0, 1, 5, 6): the MLP output here encodes token identity and local context. Tripling it distorts the representation that every later layer reads, so the target probability drops on all prompts and the distribution flattens toward high-frequency tokens such as newline, comma, period, and function words. Layer 0's MLP already dominates the residual norm, so its direction shifts less than layers 1 and 5, where the effect should be harsher.
- Middle layers (9, 10, 13): factual recall and list continuation live here. Amplification mostly over-drives whichever feature is active, hurting the lower-confidence prompts (P4, P7) more than the very confident ones (P5, P6), and promoting structural tokens and alternative list items.
- Late layers (16 to 22): these MLPs write largely in output-vocabulary directions, often toward frequent tokens, end-of-turn, and formatting tokens. Tripling them changes confident prompts only modestly, but shifts P4 and P7 noticeably toward generic continuations. Layer 22 sits right before the final norm, so its effect is most direct.
