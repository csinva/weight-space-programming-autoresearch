How I reasoned:
- **Shared embeddings:** the same row is both the token's input vector and its output vector. So an edit changes a prompt in only two ways: the edited token appears in the prompt's text, or it is one of the candidate next tokens.
- **Zeroed rows:** a row set to 0 gives that token an output logit of exactly 0. That is far below a confident top-1 logit, so the target's log-probability drops by roughly 8–12 nats. The actual logit scale is unknown, so these magnitudes are estimates.
- **Swaps and copies:** when two rows are swapped or one is copied, the target takes over the other token's probability. Where the original was in the unedited top-10 I used that listed probability; otherwise I estimated a very small one.
- **Exact ties (TO31):** copying the ' Paris' row onto ' +' gives the two tokens identical logits. ' Paris' probability is about halved (−0.65 nats on P0, −0.38 on P4).
