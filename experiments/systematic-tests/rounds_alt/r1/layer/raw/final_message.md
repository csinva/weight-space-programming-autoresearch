**How I built the estimates:**
- **Effect size:** each edit got one number, based on its layer depth and what it removes. These range from 0.4 to 1.1, with whole-block skips and the layer 23 MLP highest.
- **`dlogp`:** I multiplied that number by a fixed per-prompt profile. It assumes a perturbed model is less confident, so low-rank targets tend to gain on the most confident prompts. ' door' on P7 is the exception and is set slightly negative.
- **`p_flip`:** this uses the same effect size, scaled by how close each prompt's top two tokens are. P7 is the most likely to flip and P6 the least.

The per-edit numbers only scale this shared profile, so don't read the pattern across prompts within an edit as evidence specific to that edit.
