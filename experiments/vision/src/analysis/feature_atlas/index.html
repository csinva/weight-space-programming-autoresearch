LAION-fMRI · agentic search · interpretable model

What the searched model's 9,996 features see

The searched model has no learned weights. Every feature is a named computation on the image: a filter energy pooled over a grid cell, a co-occurrence of two channels, a statistic across scales. This atlas shows what each feature responds to in natural images, how features relate, and which ones track each brain area.

4 · Channel maps

The model's intermediate maps on six images

Before pooling, the model computes dense maps. Brighter means a stronger response. Grid features average these maps over cells; statistics features summarize them over the whole image.
