I worked from the README, test_interventions.md and the measured effects in feedback.md. Nothing could be run, so every number below is a prediction from reasoning, not a measurement.

**Method.** Each edit only changes the target's logit through its own row of the tied embedding. That gives a few simple rules:
- **Swap with token X:** the target ends up with X's old probability and the total stays the same, so dlogp = ln(p_X / p_T). This exactly reproduces TO02 (−2.636).
- **Copy X's row into the target:** the target and X both carry X's logit, so the new probability is p_X / (1 − p_T + 2·p_X). This reproduces TO04 (−1.645) and TO05 P2 (−0.596).
- **Zero the target's row:** the target drops to about −15 to −16 nats, as in TO00 and TO07.
- **Ties:** when a copy makes two tokens score equally, I assumed the lower token id wins top-1. In TO05 P2, ' +' (478) beat ' are' (513) and did not flip.

**What drives the predictions:**
- **Biggest drops:** zeroing ' are' (TO16, P7) and ' oxygen' (TO22, P5), and copying a weak token over a strong target (TO12 P0/P4, TO20 P7). All are predicted at about −8 to −15 with a near-certain flip.
- **Ties that may flip:** in TO20, ' are' (id 513) takes on the ' Paris' row, so on P0 and P4 it ties with ' Paris' (id 11751) and should win top-1. I gave these a 0.6 flip chance because I'm not sure the two logits come out exactly equal.
- **Least certain:** TO18 is the only edit that changes an input token (' Tuesday' in P3). I estimated a modest drop (−0.6) with a 0.25 flip chance.
- **Estimated probabilities:** some inputs weren't listed in the top-10 and had to be guessed: ' are' in P0/P4, ' London' in P4, ' Paris' in P7. The predictions that use them are less reliable.
- **Duplicates:** TO14 and TO17 are the same edit, so they get identical predictions. TO21 repeats TO02, so I reused the measured value.
